OptimalControlProblems.jl ​

OptimalControlProblems.jl is a collection of optimal control problems governed by ordinary differential equations, for testing and benchmarking. Each problem comes with its description, its parameters, a shared initial guess and a reference objective, and is written in one or more modelings: the continuous problem with OptimalControl.jl, a discretized problem with JuMP. The package is part of the control-toolbox ecosystem.

Each modeling is an extension

The package alone lists the problems and their metadata. A modeling becomes available when its package is loaded: using OptimalControl for the OptimalControl modelings, using JuMP for JuMP. See Installation.

The modelings ​

ModelingBackendWhat you get
OptimalControlOptimalControlBackend()The continuous problem, written with the @def syntax of OptimalControl.jl, discretized and solved by OptimalControl.solve.
OptimalControl, scalarizedOptimalControlScalarizedBackend()The same continuous problem, written with scalar components only, as needed by the ExaModels modeler on CPU and GPU.
JuMPJuMPBackend()A JuMP model, already discretized: the scheme and the grid are chosen when the problem is built.

Every problem written in two modelings is checked to give the same nonlinear program in both, and the solves of every modeling are compared to one reference objective. Each problem page shows the modelings side by side.

Quick start ​

julia
using OptimalControl, OptimalControlProblems
using NLPModelsIpopt

pb = beam(OptimalControlBackend())   # the continuous problem
sol = solve(
    model(pb), :collocation, :adnlp, :ipopt;
    init=initial_guess(pb), grid_size=500, scheme=:trapeze,
)
objective(sol)
