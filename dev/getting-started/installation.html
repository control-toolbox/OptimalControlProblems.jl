Installation ​

OptimalControlProblems.jl is a registered Julia package. In the Julia REPL:

julia
using Pkg
Pkg.add("OptimalControlProblems")

The package alone lists the problems and reads their metadata: names, parameters, statuses, initial guess and reference objective. To build a problem in a modeling, you also need the package of that modeling: each modeling is an extension, loaded when its package is.

For instance, to build the problems with OptimalControl and solve them with Ipopt:

julia
Pkg.add(["OptimalControl", "NLPModelsIpopt"])

and with JuMP:

julia
Pkg.add(["JuMP", "Ipopt"])
