Get a problem ​

Each problem in the OptimalControlProblems package is modelled in JuMP, in OptimalControl, or in both. To obtain a model, you need to specify either the JuMP or the OptimalControl backend, but first import the package:

julia
using OptimalControlProblems

Get an OptimalControl model ​

To get an OptimalControl model, first install OptimalControl and import the package:

julia
using OptimalControl

Then, to obtain the beam problem, run:

julia
pb = beam(OptimalControlBackend())
Problem beam (OptimalControl modeling, valid)
  state dimension:    2
  control dimension:  1
  variable dimension: 0

The returned Problem holds the continuous optimal control problem (OCP) and its initial guess; it is not discretised. Read it through its accessors:

julia
initial_guess(pb)
(state = [0.05, 0.1], control = 0.1)
julia
model(pb)
Abstract definition:

    t ∈ [t0, tf], time
    x ∈ R², state
    u ∈ R, control
    x(t0) == [x₁_t0, x₂_t0]
    x(tf) == [x₁_tf, x₂_tf]
    x₁_l ≤ x₁(t) ≤ x₁_u
    ẋ(t) == [x₂(t), u(t)]
    ∫(u(t) ^ 2) → min

The (autonomous) optimal control problem is of the form:

    minimize  J(x, u) = ∫ f⁰(x(t), u(t)) dt, over [0, 1]

    subject to

        ẋ(t) = f(x(t), u(t)), t in [0, 1] a.e.,

        ϕ₋ ≤ ϕ(x(0), x(1)) ≤ ϕ₊, 
        x₋ ≤ x(t) ≤ x₊, 

    where x(t) ∈ R² and u(t) ∈ R.

The scheme, the grid, the modeler and the solver are chosen when solving, see Solve a problem. You can replace any default parameter value:

julia
pb = beam(OptimalControlBackend(); parameters=(tf=2, ))

To get the list of :beam parameters and the default values, make:

julia
problem_metadata(:beam)[:parameters]
(t0 = 0, tf = 1, x₁_l = 0, x₁_u = 0.1, x₁_t0 = 0, x₂_t0 = 1, x₁_tf = 0, x₂_tf = -1)

The metadata of a built problem holds the parameters it was built with:

julia
metadata(pb)[:parameters]
(t0 = 0, tf = 2, x₁_l = 0, x₁_u = 0.1, x₁_t0 = 0, x₂_t0 = 1, x₁_tf = 0, x₂_tf = -1)

To have the description of the Beam problem parameters, either check the Beam page or the code.

Number of variables, constraints, and nonzeros ​

To get the nonlinear programming problem (NLP), discretise the OCP and build the NLP model with a modeler, here ADNLPModels.ADNLPModel:

julia
pb = beam(OptimalControlBackend())
docp = discretize(model(pb), OptimalControl.Collocation(grid_size=100, scheme=:trapeze))
init = build_initial_guess(model(pb), initial_guess(pb))
nlp = nlp_model(docp, init, OptimalControl.ADNLP())

The nlp model follows the NLPModels.jl API. See the existing Attributes and the available getter functions (get_X).

To get the number of variables, import the package:

julia
using NLPModels

and then, use the associated getter:

julia
get_nvar(nlp)
303

To get the number of constraints:

julia
get_ncon(nlp)
204

To get the number of nonzeros:

julia
nnzo = get_nnzo(nlp) # Gradient of the objective
nnzj = get_nnzj(nlp) # Jacobian of the constraints
nnzh = get_nnzh(nlp) # Hessian of the Lagrangian

println("nnzo = ", nnzo)
println("nnzj = ", nnzj)
println("nnzh = ", nnzh)
nnzo = 303
nnzj = 804
nnzh = 101

Note

You can also evaluate the objective function, the constraints, and more. See the API page.

Number of steps ​

The default number of steps is stored in the metadata:

julia
N = problem_metadata(:beam)[:grid_size]
500

Note

The grid   has length  .

The number of steps is chosen when discretising:

julia
docp = discretize(model(pb), OptimalControl.Collocation(grid_size=200, scheme=:trapeze))
get_nvar(nlp_model(docp, init, OptimalControl.ADNLP()))
603

Get a JuMP model ​

To get a JuMP model, install JuMP and import the package:

julia
using JuMP

Then, to obtain the JuMP model of the beam problem, run:

julia
nlp = beam(JuMPBackend())
A JuMP Model
├ solver: none
├ objective_sense: MIN_SENSE
│ └ objective_function_type: QuadExpr
├ num_variables: 1503
├ num_constraints: 2006
│ ├ AffExpr in MOI.EqualTo{Float64}: 1004
│ ├ VariableRef in MOI.GreaterThan{Float64}: 501

For details on how to interact with the JuMP model, see the JuMP documentation. In particular, you can pass any arguments and keyword arguments of JuMP.Model to the beam problem or any other.

julia
using Ipopt
nlp = beam(JuMPBackend(), Ipopt.Optimizer; add_bridges=true)

Note

  • As with OptimalControlBackend, you can replace any default parameter value.

  • You can transform the JuMP model into a NLPModelsJuMP.MathOptNLPModel and then use all the API of NLPModels.jl. See this tutorial for more details.
