Solve a problem ​

In this tutorial, we consider the Beam problem. First, import the OptimalControlProblems package to access the problem:

julia
using OptimalControlProblems

Solving from an OptimalControl model ​

First, get the problem:

julia
using OptimalControl
pb = beam(OptimalControlBackend())

The problem pb holds the continuous optimal control problem, model(pb), and its initial guess, initial_guess(pb). The discretisation, the modeler and the solver are chosen in solve. Here, we discretise with the trapezoidal rule on the default grid of the problem, model the NLP with ADNLPModels.jl and solve it with Ipopt:

julia
using NLPModelsIpopt

N = problem_metadata(:beam)[:grid_size]
ocp_sol = solve(
    model(pb), :collocation, :adnlp, :ipopt;
    init=initial_guess(pb),
    grid_size=N,
    scheme=:trapeze,
    tol=1e-8,
    mu_strategy="adaptive",
)

Note

The same choices can be made in explicit mode, with the strategies as arguments; see the explicit mode of OptimalControl:

julia
ocp_sol = solve(model(pb);
    init=initial_guess(pb),
    discretizer=OptimalControl.Collocation(grid_size=N, scheme=:trapeze),
    modeler=OptimalControl.ADNLP(),
    solver=OptimalControl.Ipopt(tol=1e-8),
)

To recover the state, control, and costate, use the getters of the solution:

julia
t = time_grid(ocp_sol)  # t0, ..., tN = tf
x = state(ocp_sol)      # function of time
u = control(ocp_sol)    # function of time
p = costate(ocp_sol)    # function of time
o = objective(ocp_sol)  # scalar objective value
i = iterations(ocp_sol) # number of iterations

tf = t[end]
println("tf = ", tf)
println("x(tf) = ", x(tf))
println("u(tf) = ", u(tf))
println("p(tf) = ", p(tf))
println("objective:  ", o)
println("iterations: ", i)

Note

If the problem includes additional optimisation variables, such as the final time, you can retrieve them with:

julia
v = variable(ocp_sol)

From ocp_sol you can also plot the state, control, and costate trajectories. For more details about plotting optimal control problems, see the Plot page.

julia
using Plots
plt = plot(ocp_sol; color=1, size=(700, 600), control_style=(label="OptimalControl", ))

julia
using Ipopt

# Set the optimiser
set_optimizer(nlp, Ipopt.Optimizer)

# Set optimiser attributes
set_optimizer_attribute(nlp, "tol", 1e-8)
set_optimizer_attribute(nlp, "mu_strategy", "adaptive")
set_optimizer_attribute(nlp, "linear_solver", "mumps")

# Solve the model
optimize!(nlp)

Now, we can add the state, costate, and control to the plot:

julia
n = state_dimension(nlp)
m = control_dimension(nlp)

for i in 1:n # state
    plot!(plt[i], t, t -> x(t)[i]; color=2, linestyle=:dash, label=:none)
end

for i in 1:n # costate
    plot!(plt[n+i], t, t -> -p(t)[i]; color=2, linestyle=:dash, label=:none)
end

for i in 1:m # control
    plot!(plt[2n+i], t, t -> u(t)[i]; color=2, linestyle=:dash, label="JuMP")
end

Note

The costate from JuMP is the opposite of the costate from OptimalControl, that is why we plot .

As an OptimalControl solution ​

When the problem also exists for OptimalControl, solution builds a CTModels.Solution from the solved JuMP model and the Problem of the same problem. It is then used as any OptimalControl solution: state(sol), control(sol), costate(sol), objective(sol), iterations(sol) and plot(sol).

julia
jump_sol = solution(nlp, beam(OptimalControlBackend()))
println("objective:  ", objective(jump_sol))
println("iterations: ", iterations(jump_sol))
plot(jump_sol; color=2, size=(700, 600))

Note

The costate keeps the convention of the JuMP model, whose signs differ from OptimalControl's (#326).
