OptimalControlProblems.Catalogue._fingerprint Function

Fingerprint of problem (#314): the SHA-256 of the files that define it (metadata, description, model files), recorded with each result and compared by the documentation to tell whether a result is up to date. The same on every platform: paths are relative to the package and written with /, and line endings are read as ``.

Component [Struct] ​

JuMPModels.Component Type
julia
struct Component

A component of the state, the control or the variable: its name (also the name of the JuMP container) and bounds. A bound is a number, or for the state and the control a vector over the nodes 0:N; nothing leaves it unset. The start values come from the initial guess of the problem (#377), not from the components.

source

ProblemData [Struct] ​

JuMPModels.ProblemData Type
julia
struct ProblemData

The data of an optimal control problem, written once for every scheme.

The functions receive, at one node, the vectors x (state), u (control), v (variable) of JuMP variables and the time t; x0, xf are the state at the first and last nodes.

  • times(v): the initial and final times, numbers or expressions of v.

  • dynamics(x, u, v, t): the vector ẋ.

  • lagrange(x, u, v, t): the integrand of the cost, or nothing.

  • cost(I, x0, xf, v): the objective, given the discretized integral I of the Lagrange cost (0 without one).

  • path: (lower, f, upper) with f(x, u, v, t), imposed at every node.

  • boundary: (lower, f, upper) with f(x0, xf, v).

_start! [Function] ​

JuMPModels._start! Function

Set the start values from the initial guess init ((state=…, control=…, variable=…), any of them may be missing), as CTDirect does: the state at the N+1 nodes, the control at the nodes of its M values, the variable once; the time grid is the one of the initial guess of the variable when the final time is free.

JuMPModels.control_at_node Function

control_at_node(
    tab::JuMPModels.ButcherTableau,
    k::Int64,
    N::Int64
) -> Int64

The control (0-based) used at the node k of a grid of N steps, by the path constraints. At the nodes for a tableau with final control; otherwise the control of the step that starts at the node, the last node taking the last one, except when the only stage is at the end of the step (implicit Euler): the control of the step that ends at the node, the first node taking the first one (CTDirect's conventions).
