Jackson ​

  • 3 state
  • 1 control

The Jackson problem is a classical benchmark in optimal control. It consists of controlling a three-dimensional system in which the first two states interact linearly under the effect of a single control input, while the third state accumulates based on the complementary control. The objective is to minimise the third state at the final time, while satisfying bounds on states and control, as well as initial and terminal conditions. The problem exhibits singular arcs, making it a useful benchmark for testing direct transcription and nonlinear programming methods.

Qualitative behaviour ​

  • The first two states interact linearly under the effect of the control, while the third state accumulates according to  .

  • The problem exhibits singular arcs, where the optimal control is neither at its lower nor upper bound but satisfies Hamiltonian conditions.

  • Optimal trajectories typically include bang–bang segments interleaved with singular arcs.

  • State and control constraints are respected at all times, and the final cost depends only on .

Characteristics ​

  • Linear–nonlinear three-dimensional dynamics with one control input.

  • State and control bounds.

  • Terminal cost depends on a single state.

  • Serves as a benchmark for testing solvers handling singular arcs and constrained optimal control.

References ​

  • Jackson, E. A. (1968). The existence of singular extremals. Journal of Optimization Theory and Applications. Discusses the theoretical existence of singular extremals, forming the basis of the Jackson benchmark problem.

  • Biegler, L. T. (2010). Nonlinear Programming: Concepts, Algorithms, and Applications to Chemical Processes. SIAM. Provides background on nonlinear programming methods applicable to problems like Jackson.

  • BOCOP Repository: Jackson Example. https://github.com/control-toolbox/bocop/tree/main/bocop Contains the Jackson problem implementation for testing direct transcription and NLP solvers.

OptimalControl ​

valid

The continuous problem, written with the @def syntax of OptimalControl.jl, discretized and solved by OptimalControl.solve. Load OptimalControl and NLPModelsIpopt.

Get and solve ​

julia
using OptimalControl, OptimalControlProblems
using NLPModelsIpopt

pb = jackson(OptimalControlBackend())
sol = solve(
    model(pb), :collocation, :adnlp, :ipopt;
    init=initial_guess(pb),
    grid_size=500,
    scheme=:trapeze,
)
objective(sol)

The model ​

The model as written in ext/OptimalControlModels/jackson.jl, where the parameters are read from the metadata.

julia
ocp = @def begin
    t ∈ [t0, tf], time
    x = (a, b, x₃) ∈ R³, state
    u ∈ R, control

    x(t0) == [a_t0, b_t0, x₃_t0]

    [a_l, b_l, x₃_l] ≤ x(t) ≤ [a_u, b_u, x₃_u]
    u_l ≤ u(t) ≤ u_u

    ẋ(t) == [
        -u(t) * (k1 * a(t) - k2 * b(t)),
        u(t) * (k1 * a(t) - k2 * b(t)) - (1 - u(t)) * k3 * b(t),
        (1 - u(t)) * k3 * b(t),
    ]

    -x[3](tf) → min
end

OptimalControl, scalarized ​

valid

The same continuous problem, written with scalar components only, as needed by the ExaModels modeler on CPU and GPU. Load OptimalControl and MadNLP.

Get and solve ​

julia
using OptimalControl, OptimalControlProblems
using MadNLP

pb = jackson(OptimalControlScalarizedBackend())
sol = solve(
    model(pb), :collocation, :exa, :madnlp;
    init=initial_guess(pb),
    grid_size=500,
    scheme=:trapeze,
)
objective(sol)

The model ​

The model as written in ext/OptimalControlScalarizedModels/jackson.jl, where the parameters are read from the metadata.

julia
ocp = @def begin
    t ∈ [t0, tf], time
    x = (a, b, x₃) ∈ R³, state
    u ∈ R, control

    x(t0) == [a_t0, b_t0, x₃_t0]

    [a_l, b_l, x₃_l] ≤ x(t) ≤ [a_u, b_u, x₃_u]
    u_l ≤ u(t) ≤ u_u

    ∂(x₁)(t) == -u(t) * (k1 * a(t) - k2 * b(t))
    ∂(x₂)(t) == u(t) * (k1 * a(t) - k2 * b(t)) - (1 - u(t)) * k3 * b(t)
    ∂(x₃)(t) == (1 - u(t)) * k3 * b(t)

    -x₃(tf) → min
end

JuMP ​

valid

A JuMP model, already discretized: the scheme and the grid are chosen when the problem is built. Load JuMP and Ipopt.

Get and solve ​

julia
using JuMP, Ipopt, OptimalControlProblems

nlp = jackson(
    JuMPBackend();
    grid_size=500,
    scheme=:trapeze,
)
set_optimizer(nlp, Ipopt.Optimizer)
optimize!(nlp)
objective_value(nlp)

The model ​

The model as written in ext/JuMPModels/jackson.jl, where the parameters are read from the metadata.

julia
data = ProblemData(;
    state=[
        Component("a"; lower=a_l, upper=a_u),
        Component("b"; lower=b_l, upper=b_u),
        Component("x₃"; lower=x₃_l, upper=x₃_u),
    ],
    control=[Component("u"; lower=u_l, upper=u_u)],
    costate=["∂a", "∂b", "∂x₃"],
    times=v -> (t0, tf),
    dynamics=(x, u, v, t) -> dynamics(x, u),
    cost=(I, x0, xf, v) -> -xf[3],
    boundary=[
        (a_t0, (x0, xf, v) -> x0[1], a_t0),
        (b_t0, (x0, xf, v) -> x0[2], b_t0),
        (x₃_t0, (x0, xf, v) -> x0[3], x₃_t0),
    ],
)

Comparison of the modelings ​

Same problem ​

Two modelings of the same problem, discretized the same way, must give the same nonlinear program: same variables, constraints, objective and derivatives at the initial guess. This is what is compared, not the solutions: two solves are two optimization paths.

  • OptimalControl, scalarized and OptimalControl: same NLP, checked on every pull request.

  • JuMP and OptimalControl: same NLP, checked on every pull request.
