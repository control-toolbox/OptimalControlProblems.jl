The insurance problem is a benchmark in optimal control inspired by health and financial economics. It consists of controlling insurance coverage, expenses, revenue, health, and utility over a fixed horizon to maximise expected utility. The system dynamics model the evolution of insurance participation, expenses, and auxiliary variables, while respecting bounds on all state and control variables. The controls represent health investments, insurance revenue, health outcomes, and utility contributions.

Qualitative behaviour ​

  • The optimal strategy balances insurance coverage, health investment, and expenses to maximise utility under constraints.

  • Revenue and health constraints link controls and states nonlinearly.

  • The dynamics incorporate moral hazard effects and diminishing returns on expenses.

  • Auxiliary variables track utility and revenue derivatives, ensuring consistent constraints.

Characteristics ​

  • Nonlinear three-dimensional state dynamics with five control variables and one auxiliary.

  • Fixed final time with state and control bounds.

  • Models health insurance optimisation under ex post moral hazard and risk-sensitive utility.

  • Serves as a benchmark for testing constrained nonlinear OCP solvers.

OptimalControl ​

valid

The continuous problem, written with the @def syntax of OptimalControl.jl, discretized and solved by OptimalControl.solve. Load OptimalControl and NLPModelsIpopt.

Get and solve ​

julia
using OptimalControl, OptimalControlProblems
using NLPModelsIpopt

pb = insurance(OptimalControlBackend())
sol = solve(
    model(pb), :collocation, :adnlp, :ipopt;
    init=initial_guess(pb),
    grid_size=500,
    scheme=:trapeze,
)
objective(sol)

The model ​

The model as written in ext/OptimalControlModels/insurance.jl, where the parameters are read from the metadata.

julia
ocp = @def begin
    P ∈ R, variable
    t ∈ [t0, tf], time
    x = (I, m, x₃) ∈ R³, state
    u = (h, R, H, U, dUdR) ∈ R⁵, control

    # constraints
    I_l ≤ I(t) ≤ I_u
    m_l ≤ m(t) ≤ m_u
    h_l ≤ h(t) ≤ h_u
    R(t) ≥ R_l
    H(t) ≥ H_l
    U(t) ≥ U_l
    dUdR(t) ≥ dUdR_l
    P ≥ P_l

    x(t0) == [I_t0, m_t0, x₃_t0]
    P - x₃(tf) == 0

    #
    ε = k * (t - t0) / (tf - t + 1)

    # illness distribution
    fx = λ * exp(-λ * (t - t0)) + exp(-λ * (tf - t0)) / (tf - t0)

    # expense effect
    v = m(t)^(α / 2) / (1 + m(t)^(α / 2))
    vprime = α / 2 * m(t)^(α / 2 - 1) / (1 + m(t)^(α / 2))^2

    # constraints
    R(t) - (w - P + I(t) - m(t) - ε) == 0
    H(t) - (h0 - γ * (t - t0) * (1 - v)) == 0
    U(t) - (1 - exp(-s * R(t)) + H(t)) == 0
    dUdR(t) - (s * exp(-s * R(t))) == 0

    # dynamics
    ẋ(t) == [(1 - γ * (t - t0) * vprime / dUdR(t)) * h(t), h(t), (1 + σ) * I(t) * fx]

    # objective
    -∫(U(t) * fx) → min
end

OptimalControl, scalarized ​

valid

The same continuous problem, written with scalar components only, as needed by the ExaModels modeler on CPU and GPU. Load OptimalControl and MadNLP.

Get and solve ​

julia
using OptimalControl, OptimalControlProblems
using MadNLP

pb = insurance(OptimalControlScalarizedBackend())
sol = solve(
    model(pb), :collocation, :exa, :madnlp;
    init=initial_guess(pb),
    grid_size=500,
    scheme=:trapeze,
)
objective(sol)

The model as written in ext/OptimalControlScalarizedModels/insurance.jl, where the parameters are read from the metadata.

    t ∈ [t0, tf], time
    x = (I, m, x₃) ∈ R³, state

    h_l ≤ h(t) ≤ h_u

    U(t) ≥ U_l

    P - x₃(tf) == 0

    # illness distribution
    fx = λ * exp(-λ * (t - t0)) + exp(-λ * (tf - t0)) / (tf - t0)

    # expense effect
    v = m(t)^(α / 2) / (1 + m(t)^(α / 2))

    U(t) - (1 - exp(-s * R(t)) + H(t)) == 0

    ∂(I)(t) == (1 - γ * (t - t0) * vprime / dUdR(t)) * h(t)

JuMP ​

valid

A JuMP model, already discretized: the scheme and the grid are chosen when the problem is built. Load JuMP and Ipopt.

Get and solve ​

julia
using JuMP, Ipopt, OptimalControlProblems

nlp = insurance(
    JuMPBackend();
    grid_size=500,
    scheme=:trapeze,
)
set_optimizer(nlp, Ipopt.Optimizer)
optimize!(nlp)
objective_value(nlp)

The model ​

The model as written in ext/JuMPModels/insurance.jl, where the parameters are read from the metadata.

julia
data = ProblemData(;
    state=[
        Component("I"; lower=I_l, upper=I_u),
        Component("m"; lower=m_l, upper=m_u),
        Component("x₃"),
    ],
    control=[
        Component("h"; lower=h_l, upper=h_u),
        Component("R"; lower=R_l),
        Component("H"; lower=H_l),
        Component("U"; lower=U_l),
        Component("dUdR"; lower=dUdR_l),
    ],
    variable=[Component("P"; lower=P_l)],
    costate=["∂I", "∂m", "∂x₃"],
    times=v -> (t0, tf),
    dynamics=(x, u, v, t) -> dynamics(x, u, t),
    lagrange=(x, u, v, t) -> u[4] * fx(t),
    cost=(integral, x0, xf, v) -> -integral,
    path=[
        (0, (x, u, P, t) -> u[2] - (w - P[1] + x[1] - x[2] - ε(t)), 0),
        (0, (x, u, P, t) -> u[3] - (h0 - γ * (t - t0) * (1 - v(x[2]))), 0),
        (0, (x, u, P, t) -> u[4] - (1 - exp(-s * u[2]) + u[3]), 0),
        (0, (x, u, P, t) -> u[5] - (s * exp(-s * u[2])), 0),
    ],
    boundary=[
        (I_t0, (x0, xf, v) -> x0[1], I_t0),
        (m_t0, (x0, xf, v) -> x0[2], m_t0),
        (x₃_t0, (x0, xf, v) -> x0[3], x₃_t0),
        (0, (x0, xf, v) -> v[1] - xf[3], 0),
    ],
)

Two modelings of the same problem, discretized the same way, must give the same nonlinear program: same variables, constraints, objective and derivatives at the initial guess. This is what is compared, not the solutions: two solves are two optimization paths.
